# Crimson Pro

These unmodified WOFF2 files are the Latin subset of **Crimson Pro**, with a
variable weight axis from **200 to 900** and separate normal and italic styles.
They are served locally so the homepage does not need a font CDN.

| File | Style | Weight range | Bytes |
| --- | --- | --- | ---: |
| `crimson-pro-latin-wght-normal.woff2` | normal | 200–900 | 48,200 |
| `crimson-pro-latin-wght-italic.woff2` | italic | 200–900 | 51,432 |

Source: [Fontsource Crimson Pro](https://fontsource.org/fonts/crimson-pro),
[`@fontsource-variable/crimson-pro` version 5.3.0](https://www.npmjs.com/package/@fontsource-variable/crimson-pro/v/5.3.0).

The package identifies [Google Fonts](https://github.com/google/fonts/tree/main/ofl/crimsonpro)
as its upstream source (font version v28).

Declare the faces under `font-family: "Crimson Pro"`, with `font-weight: 200 900`
and the corresponding `font-style: normal` or `italic`. Fontsource's packaged
CSS uses `"Crimson Pro Variable"` as its CSS alias; the actual typeface is
Crimson Pro. Use the same family name in both declarations and site styles.

These files cover Latin characters rather than Chinese text. The package's
Latin Unicode range is:

```text
U+0000-00FF,U+0131,U+0152-0153,U+02BB-02BC,U+02C6,U+02DA,U+02DC,U+0304,U+0308,U+0329,U+2000-206F,U+20AC,U+2122,U+2191,U+2193,U+2212,U+2215,U+FEFF,U+FFFD
```

# Noto Serif SC — Chinese name subset

`noto-serif-sc-name-500.woff2` contains the four characters **杨佳宇轩** for
the sidebar name, in normal style at weight **500** (1,732 bytes). It is a
static font subset generated by the official Google Fonts `text` API, rather
than a complete Chinese font. A space and the font's missing-glyph entry are
also present. If the Chinese name changes, regenerate or extend the subset
to cover every new character.

Downloaded on 2026-10-02 using this
[Google Fonts CSS request](https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@500&text=%E6%9D%A8%E4%BD%B3%E5%AE%87%E8%BD%A9&display=swap).
